Friendship City Game 🎮

An interactive 2D graphics game developed as a team project using C++, OpenGL, and GLUT.

Project Overview

Friendship City Game consists of four interconnected scenes combining computer graphics, animation, and interactive gameplay.

Game Features

* Scene 1 – City Introduction: A graphical introduction to the game environment.
* Scene 2 – Star Collection: An interactive mini-game where the player moves around the scene to collect stars and earn points.
* Scene 3 – Star Animation: Animated graphics demonstrating translation, rotation, and scaling.
* Scene 4 – Interactive Gift: A scene that allows users to select gift colors through keyboard and mouse interactions.
